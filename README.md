# Zento Official Website

A React + Vite starter for Zento's official digital solutions and technology website.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` before deployment.

## Routes
- `/` — Home
- `/solutions` — Agency services
- `/products` — Zento software products
- `/about` — About Zento
- `/contact` — Contact enquiry

## Before launch
- Register and connect `zento.com.ng`; configure the official business email before publishing contact details.
- Connect the enquiry form to a secure form provider, CRM, or backend endpoint. The current form only copies the enquiry locally; it does not transmit or store submissions.
- Add verified portfolio projects, screenshots, testimonials and product links only when ready.
- Add final legal pages, analytics, social links and SEO metadata.
- Configure the domain and HTTPS in the hosting provider.
